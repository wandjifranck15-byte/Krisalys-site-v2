Déposez ici les images réelles de KRISALYS (façades, écrans LED, projets,
équipe...) au format .webp ou .avif de préférence, pour remplacer les blocs
de couleur temporaires utilisés dans les composants Hero, ProjectCard et
BeforeAfterSlider. Voir le README principal, section 6.

## Médias déjà intégrés (19 juillet 2026)

  fourni par Franck. Utilisé par `components/ui/Logo.tsx`.
- `brand_mark_k.png` — "K" seul, recadré depuis le même fichier source. Prévu pour de futurs contextes
  compacts (variant="mark" de `Logo.tsx`, non encore utilisé sur une page).

  (`app/layout.tsx`).

Sources originales (non recadrées) conservées dans `/KRISALYS-Media/01-Brand/Logo/` et
`.../Favicon/` du KOS. Les fichiers ci-dessus sont en PNG raster (le fichier source était un JPEG) ;
une version vectorielle (SVG) reste à produire si une déclinaison print ou très haute résolution est
nécessaire.
